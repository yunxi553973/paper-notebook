# 纸质笔记本

一个单文件、零依赖的**纸质风格记笔记网站**。打开一个 HTML 文件即可使用，所有数据保存在你自己的浏览器里，不上传任何服务器。

## 项目是做什么的

模拟真实笔记本的使用体验：

- **书架主页**：以木质书架陈列你的所有笔记本，可创建多本、自定义名称与封皮颜色；点击书本有开书 3D 动画
- **四种记录方式**：打字（逐条笔记）、手写（画笔涂鸦）、插入图片、录制语音
- **纸张自定义**：每页可切换空白 / 横线 / 方格样式，自定义纸张底色，或用照片作页面背景
- **翻页与目录**：3D 翻页动画；每新建一页会提醒创建目录（新建标题或跟随上一页目录）；鼠标靠近页面左缘自动滑出目录，点击条目可跳转
- **时间戳**：每条笔记（文字 / 图片 / 语音）自动盖上精确到秒的创建时间戳
- **书架主题**：书架页提供简约 / 卡通 / 复古 / 科技 / 自然五套背景风格

## 怎样使用

### 方式一：直接打开（最简单）

1. 下载 `纸质笔记本.html`
2. 双击用浏览器打开（推荐 Chrome / Edge / Firefox）
3. 点「新建笔记本」→ 起名、挑封皮 → 创建后点书架上的书本即可开始写

> 注意：语音录制需要麦克风权限。`file://` 协议下 Chrome 允许录音，若你的浏览器拦截，请改用方式二。

### 方式二：本地服务器（推荐，支持录音更稳定）

```bash
# 任选其一，在本目录执行：
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/纸质笔记本.html`

### 方式三：GitHub Pages

仓库 Settings → Pages → 选择分支即可上线，之后任何设备都能通过链接访问（数据仍存在各自浏览器本地）。

### 日常操作速查

| 操作 | 方法 |
|---|---|
| 新建一条笔记 | 工具栏「条目」按钮 |
| 手写 | 工具栏「手写」→ 画完后点「完成」 |
| 插入图片 | 工具栏「图片」，可多选 |
| 录语音 | 工具栏「语音」→ 开始 / 停止 |
| 翻页 | 下方圆形按钮，或键盘 ← / → |
| 新建一页 | 工具栏「新页」，弹窗中创建目录 |
| 打开目录 | 鼠标移到页面左边缘 |
| 删除某条笔记 | 鼠标悬停条目右上角 ✕ |
| 删除笔记本 | 书架上悬停书本左上角 ✕ |
| 保存 | 全程自动，无需手动操作 |

## 输入条件（细则）

| 输入类型 | 接受的格式 / 条件 | 处理方式 |
|---|---|---|
| 文字 | 任意文本，支持富文本粘贴（加粗、换行等基础样式） | 以 HTML 片段存储，停顿 0.4 秒后自动保存 |
| 手写 | 鼠标拖动、触屏手指、触控笔（Pointer Events）；可选 3 色 × 10 级粗细 | 以绝对像素坐标记录笔迹，页面变长不变形 |
| 图片 | JPG / PNG / GIF / WebP 等浏览器可解码格式，可一次多选 | 自动等比缩放至最长边 ≤ 1200px，转为 JPEG（质量 0.82）存储 |
| 页面背景图 | 同图片 | 缩放至最长边 ≤ 1600px，JPEG（质量 0.7），叠加半透明纸色蒙版保证文字可读 |
| 语音 | 浏览器支持的录音格式（通常 WebM/Opus） | 需授权麦克风；转 Base64 存储；取消或录出空音频不会生成条目 |
| 封皮 / 主题 | 封皮 6 色可选；书架主题 5 种 | 即点即生效并记忆 |
| 纸张 | 底色任意（颜色选择器）；样式三选一 | 新页默认继承上一页的纸张设置 |

**环境要求**：现代浏览器（Chrome 90+ / Edge 90+ / Firefox 90+ / Safari 14+），需支持 IndexedDB 与 Pointer Events。语音功能需 HTTPS 或 localhost 环境 + 麦克风授权。

## 输出 / 存储条件（细则）

### 存储位置

数据保存在浏览器的 **IndexedDB** 中：

- 数据库名：`paperNotebookDB`
- 对象仓库：`kv`，单条记录，键为 `state`
- 容量上限：按磁盘可用空间计算（通常数百 MB 起），远超 localStorage 的约 5MB
- 首次从旧版本（localStorage）打开时会自动迁移，迁移为复制而非删除

### 数据结构

存储内容为一整个 JSON 对象，结构如下：

```jsonc
{
  "notebooks": [
    {
      "id": "lh8x2k…",              // 唯一 ID
      "name": "手帐 · 2026",         // 笔记本名称
      "color": "#8B5E3C",           // 封皮颜色
      "createdAt": "2026-10-22T…",
      "pages": [
        {
          "id": "…",
          "tocTitle": "第一章",      // 目录标题
          "tocFollow": false,       // true 表示跟随上一页目录
          "createdAt": "ISO 时间",
          "paper": {
            "style": "lined",       // blank | lined | grid
            "bg": "#FFFDF5",        // 纸张底色
            "bgImage": null         // 背景图 dataURL 或 null
          },
          "strokes": [              // 手写笔迹
            { "v": 2, "color": "#3E3228", "w": 3, "pts": [[120.5, 88], [121, 89]] }
          ],
          "blocks": [               // 笔记条目（按插入顺序）
            { "id": "…", "type": "text",  "time": "2026-10-22 20:31:05", "html": "…" },
            { "id": "…", "type": "image", "time": "…", "src": "data:image/jpeg;base64,…" },
            { "id": "…", "type": "audio", "time": "…", "src": "data:audio/webm;base64,…", "dur": 12 }
          ]
        }
      ]
    }
  ],
  "current": null,                  // 当前打开的笔记本 ID（会话状态）
  "settings": { "theme": "minimal" } // 书架主题
}
```

### 数据边界（重要）

- 数据与「**这台电脑 + 这个浏览器 + 这个文件源（同源）**」绑定；换设备、换浏览器或无痕模式下不可见
- 清除浏览器「站点数据」会**永久删除**笔记
- 所有内容仅存本地，**不会**发送到任何服务器
